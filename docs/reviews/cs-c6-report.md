## 4. 我替你定的

- 排序的「打乱」从已配置的种子起步，缺省从 0 起步，点击后种子加 1，再洗牌当前数据。比赛中先结束的一栏保留末帧，公共进度条可以继续到最后一栏结束。
- 寻路用 HTML canvas。小图在格内显示分数，大图用点选或方向键查看。拖动地图到松手时一次提交，两栏共用编辑结果。连续播放按帧累计应走的步数，每帧最多补四步，离屏或隐藏标签期间不积攒欠步。每次切换帧都对照队列、已扩展标志和格内数值重画，包括 DFS 在一步末尾丢掉旧栈项的格子。
- 图沿用作者给的结点位置，边遇到非端点结点时弯绕。数值标签按入边和出边的方向选择位置，结点中心保留原生点击区。邻接表和矩阵在自己的框内滚动。
- 四种组件在读者修改参数时重建本次轨迹，速度和焦点保留。寻路权重可连续输入小数，按回车或移开焦点时提交有效值。
