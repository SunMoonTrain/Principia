## 重要 1 · 电路图里不同信号的线会重合

- 位置：`packages/sim/src/circuit-layout.ts:83`–`86`。每根线的偏移 `lane = (wires.length % 5) * 4` 只看它是第几根线；相邻两列之间的竖段放在 `b.x − 22 − lane`，跨列的放在 `b.x − 16 − lane`，横段放在源那一行下方的 `lanes.get(row) + lane`（`:78`）。两种竖段交错，间距只有 2 像素；第几根线对 5 取余相同的两根线还会落在同一位置。
- 依据：`docs/cs-plan.md`「C2 / 验收」画面那一条，「每根线从源的输出脚连到目标的输入脚」，前提是读者能顺着线看出来；「组件怎么动」：「线按 0 / 1 着色、旁边标值」。
- 现象（在画廊 7 个电路里量的，只算不同信号）：
  - 正好重合 2 处。计数器 `x1 → Q1.D` 和 `Q1 → C1` 在 y = 275 重合 160 像素，汇报截图 [counter-dark.jpg](cs-c2/counter-dark.jpg) 中间那条长横线就是这两根线。行波加法器 `A3` 和 `u2.s` 重合 8 像素。
  - 只隔 2 像素并排的 8 处，长 31～97 像素。计数器触发器左边那条缝里，6 根竖线（4 个不同信号）挤在 14 像素内（x = 150、152、154、160、162、164）；全加器 `Cin` 和 `x1` 各一根；行波加法器接输出灯的那条缝里 3 处。线宽 1.5～2 像素，隔 2 像素看上去就是一根。
  - 线只按 0 / 1 两种颜色画，后画的盖住先画的。两根值不同的线重合时，那一段显示的是后画那根的值：计数器里 x1 = 1、Q1 = 0 时，x1 那根线有 160 像素显示成 0。计数器正是要顺着反馈线看「下一个状态从哪来」的演示。
- 怎么修（建议）：按通道分配走线道。每两列之间的缝是一条竖通道，每两行之间的空隙是一条横通道。把每段线在通道里占的范围当成一个区间，区间重叠而信号不同的分到不同的道（同一信号可以共用一条道），道和道之间至少隔 6 像素左右，道多了就加宽缝或空隙。汇报里的检查只核了端点，请补一条测试：7 个画廊网表（最好再加一批随机网表）里，任意两段不同信号的平行线段只要沿线方向有重叠，间距就不能小于道距。

## 小问题

### ①「到稳定」「半个周期」每一步没有上限

- 位置：`packages/sim/src/core/circuit.ts:75` 的循环一直走到稳定、发现重复，或者拍号到 2⁵³ − 1。`:76`–`85` 跳过整周期的办法，要先遇到重复的状态才起作用。
- 现象：用环形振荡器带一串 dff 分频（无时钟，每个 dff 的时钟接上一级的 Q）。16 级时「到稳定」一步走 131,073 拍，Node 里约 0.5 秒，每多一级时间翻倍。20 级（顶层 22 个元件、展开后 41 个门，都在上限内）按翻倍推算约 8 秒。借子电路能写到 38 级，那就永远回不来，`repeated` 每拍多一条，内存一直涨。有时钟时也一样：`every` 很大、半个周期里内部状态又不重复，就要逐拍走完 `every` 拍。真实内容一般碰不到，可一旦碰到，卡住的是读者的整个页面。
- 怎么修（建议）：每一步按实际计算的拍数封顶，比如 10,000 拍。到了上限还没稳定、也没发现重复，就停下，说明里写清「算了 N 拍还没稳定，也没发现重复」，不置 `osc`，也不暂停。「半个周期」同样按实际调用的次数封顶。写进 `plan.md`，补一条测试。

### ② 第 0 拍触发器的「上一拍时钟」怎么算，没写进 `plan.md`

- 位置：`packages/sim/src/core/circuit.ts:56`。第 0 拍把 dff 记的上一拍时钟设成第 0 拍自己的值，所以时钟输入的初值为 1 不算上升沿。汇报「我替你定的」第 4 条写了这一点，`docs/plan.md:2033` 附录 C「数字电路」那一格没有写。
- 后果：写内容的人照附录推答案，遇到时钟输入接开关且开关初值为 1（或者接一个 `init` 为 1 的门）时，会以为第 0 拍有一次上升沿。把这句补进附录 C 那一格就行。
