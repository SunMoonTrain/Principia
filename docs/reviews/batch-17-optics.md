## 重要 1 · `resolving-power` 的艾里斑动画在一些宽度下峰顶掉到零

- 位置：`resolving-power/lesson.md:56`、`:59`、`:62` 三条曲线都用 `2*sum(...)/48/(pi*(x ± 0.61*s) + 1e-9)`。
- 问题：样点正好落在艾里斑中心时，分子是十几位小数的舍入误差，分母是 `1e-9`，算出约 `1e-17`，曲线在峰顶画一条竖线掉到零。FunctionPlot 每像素取两个样点，样点落不落在中心取决于画布宽度和滑块值。
  - 脚本 `scratchpad/checks/airy2.ts` 用组件同一个求值器算：画布宽 560–1000 px 里，654、774、804、854、954 px 时都有滑块值命中，其中 654、954 px 正是默认的 s = 1。
  - 在页面上把视口调到 716 px，画布正好 654 px。
- 建议：换成没有除法的式子，`z = 0` 时自然等于 1：

  $\frac{2J_1(z)}z=\frac4\pi\int_0^{\pi/2}\cos^2\varphi\cos(z\sin\varphi)\,\dd\varphi$

  取 48 个中点就是 `sum(j, 0, 47, cos(pi*(j + 0.5)/96)^2*cos(pi*X*sin(pi*(j + 0.5)/96)))/24`，`X` 换成 `x + 0.61*s` 或 `x - 0.61*s`，再平方。这正是讲解里「按长度加权的细条」的积分，说明文字不用改。

## 小问题 3 · 选项和表述

- **fourier-optics 第 2 题 B**：「单缝的宽度加倍，中央亮纹的角宽度减半」，标准答案判对。但只在角度小时才成立：缝宽 1.5λ 时半角宽 41.8°，加倍后 19.5°，不是一半。解答里已经写了「角度小时」，选项里也要写（plan.md:300 选项写清前提）。
- **polarization 第 2 题 E**：Eₓ = A cos(ωt − kz)、E_y = A sin(ωt − kz) 是左旋。这正是讲解 `:31`、`:36` 已经判过的 δ = π/2（「E_y = ±A sin ωt」「δ = π/2 时……是左旋」）和例 2，属于照搬（plan.md:227）。建议换成讲解没判过的情形，例如 δ = −3π/4，或振幅不等。
- **birefringence `:16`**：开头问「3D 电影眼镜里的薄晶片怎样把线偏振光变成圆偏振光」。可 `:69` 讲的是眼镜里的四分之一波片把圆偏振光变回线偏振光，方向说反了。
- **birefringence `:55`**：波片定义里「电场沿光轴和垂直于光轴的两个分量方向相同、速度不同」，读起来像两个分量方向相同。建议改成「传播方向相同」。
- **michelson `:58`**：「钠灯的两条黄线一样亮」当事实说了。实际 D₂ 约是 D₁ 的两倍亮，可见度的极小不到零，约 1/3。建议写成「设两条黄线一样亮（实际 D₂ 约是 D₁ 的两倍，可见度降不到零）」或「亮度相近」。默认动画的「每隔约 0.29 mm 降到零一次」也照此加「设一样亮」。
