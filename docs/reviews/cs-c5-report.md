## 4. 我替你定的

- 数组的多组 insert 按「下标、值」成对展开。运行失败也消耗一个操作序号。开放表迁移时实际读过的新槽计入 probes，搬进一个键计一次 moves。链表没有单独的容量变量，capacity 读作 0。
- 图中用 ∅、·、† 分别表示空指针、空槽和墓碑。队列 H/T 是队首下标和下次写入下标。申请和释放以虚线标出涉及的字节，读写另用底色；旧字节随当前分配状态解释。
- 两种新组件共用内存格。CPU 继续使用原有的内存面板。新播放器对空脚本在第 0 步就允许编辑并显示已结束；现有机器未提供这个可选判定，原有的步进行为保持原样。
