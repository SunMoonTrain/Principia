## 4. 我替你定的

- 三种新结构从 tree 分别按需加载，各自维护内核；共用一套按子树宽度排布的森林视图。用地址标识结点，待接入和待释放的块在过渡微步也能看到。字典树虚根保留为一个可选的小点。
- 点击结构或内存会联动选中同一结点。框能同时容下本步触点时一起显示；跨度超过框宽或框高时优先定位本步写入的位置。内存仍可滚动查看其他地址。
- B 树取前驱、后继和读兄弟时，在事件说明里交代读哪个结点和为什么。整操作粒度保留情形理由，微步粒度可分开看取键、替换和释放。插入演示在首次分根的操作完成后暂停，便于先猜分隔键。
- 字典树的前缀结果按字母序写在本次操作的最后一个微步，`matches` 保留到下次 prefix。没有匹配也会把它更新为 0。
