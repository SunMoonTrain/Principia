### 处理器和内容块

| 验收项 | 方法与实测结果 |
| --- | --- |
| 汇编与反汇编 | 内核测试断言 A1 的 14 个字节为 `14 0A 15 00 41 00 64 01 A8 04 E5 00 00 00`，`loop = 0x04`。穷举 65,536 对字节，其中 11,435 对合法，覆盖 27 个助记符。将全部合法编码反汇编、再汇编，字节逐对相等。 |
| 非法指令 | `08 00`、`00 05`、`41 04` 均反汇编为 `.byte`。在 NOP 后放 `41 04`，只完成 1 条、用 1 周期，译码提示源寄存器编号只允许 0–3。 |
| A1 累加 | 两种粒度分别运行到 HLT，都得到 34 条、34 周期、输出 [55]，Z/N/C/V 为 1/0/0/0。逐微步共 136 步。第一条依次显示读出 `14 0A` 和 PC 加 2、译出 LDI R0 和立即数 10、准备写 10 且保留标志、R0 写入 10。浏览器两种粒度都在第 32 条完成时触发 PC 暂停点，R1 为 55。 |
| A2 栈 | 每条周期用测试锁为 1、11、1、11、1。停机时 5 条、25 周期，R0 = 9、R1 = 7、SP = 0xFF、M[0xFF] = 7。逐微步检查 PUSH 在写回才改内存，POP 在执行读出 7、写回才改 R1。 |
| A3 子程序 | CALL 后 PC = 0x08、SP = 0xFE、M[0xFF] = 0x04。浏览器的栈格显示「返回地址」。RET 后 PC = 0x04、SP = 0xFF。6 条、26 周期，输出 [42]。 |
| 标志 | 表驱动测试逐项比较结果与全部四个标志。0x7F + 1 得 0x80，置 N/V；0xFF + 1 得 0，置 Z/C。0 − 1 得 0xFF，置 N/C；0x80 − 1 得 0x7F，置 V。SHL 0x81 得 2，置 C；SHR 1 得 0，置 Z/C。CMP 3, 5 置 N/C，R0 仍为 3。随后 LDI 保留四个标志。 |
| 栈覆盖代码 | 测试与画廊都在第 503 条完成时停于 SP = 3。第 253 次 PUSH（第 505 条）写 0x03，出现「栈进入了程序区」。第 254 次 PUSH 改掉 0x02 的 JMP，下一条执行 `00 00`。第 508 条停机，总计 3048 周期。 |
| 修改指令字节 | 在 A1 内存格把 0x04 的值从 0x41 改成 0x45，页面标出「内存里已改成 SUB R1, R0」，继续运行输出 [201]。 |
| 输出和输入边界 | OUT/JMP 循环先完成 512 条，第 257 次 OUT 在执行阶段报错，界面保留 256 行输出。单独运行受限指令演示，255 的同一行显示 255、−1、0xFF、—。重新装入 IN/OUT 和全角输入 `０ｘＦＦ`，从第 0 步开始并输出 0xFF。PC = 0xFF 时也测试了跨到 0x00 读取第二字节。 |
| 汇编诊断 | 用例覆盖未知 MUL、LDI 使用寄存器立即数、256 和 −129、R4、缺操作数、未定义和重复标号、保留名、超出 256 字节与 .org 重叠。错误带源行，重叠还给出先前那一行。可确定的前向地址正常解析，循环依赖报错。 |
| 微步面板与历史 | 浏览器实看指令寄存器的三个分色字段、ADD 的两个输入与和、PUSH 的地址与数据。单步与后退可回到译码；中途不能改状态，切到指令粒度会走完当前指令。回到指令边界把 R1 改为 99，测试确认历史末端回到当前步，下一条 LDI 将 R1 写为 0。 |
| 断点 | 在 A1 点 `loop` 的行号设置断点，按运行十次，停在第 2、5、8、11、14、17、20、23、26、29 条之后。R1 依次为 0、10、19、27、34、40、45、49、52、54。再次运行经过第 32 条的教学暂停点，继续后停机并达成输出目标。 |

## 4. 我替你定的

- 编辑器在输入时同步标出首个汇编错误。点击运行后在专用 Worker 跑用例，编辑源码或离开题卡会终止旧任务，旧结果不能记到新代码上。
- 判题用共享的译码、执行、写回规则，不保存交互历史。预算在一条访存指令中途用尽时，显示用尽的周期数，尚未完成的指令不写回。
- 画廊夹具开放全部指令，方便在同一道题上试死循环和输入耗尽。四条指令的限制在单独的处理器演示里体验。
- 前向标号参与 .org 或 .zero 时按地址依赖求值。正常指令和数据的前向引用同样可用。解不开的位置循环会指出引用行。
