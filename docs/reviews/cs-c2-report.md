## 4. 我替你定的

- 缺省显示电路图。顶层 40 个元件按实际画出的开关、时钟、门或实例、输出灯计数。多个门指定同一格时，第一个使用该格，其他门依次使用空行。
- 「半个周期」从当前拍走到下一个 CLK 翻转处。「到稳定」到达稳定态或首次检测到重复时返回。两种粒度都保存中途每一拍的波形。稳定和振荡会暂停播放，读者可以继续单步或改输入。
- 子电路的引脚名显示在方框两侧。条件要读实例输出脚时，给它接一个顶层具名输出；时序探针可直接写 `u1.cout`。名字相同的输出灯可以直连同名门，例如 `Q: Q`。
- 第 0 拍将触发器先前的时钟电平设为当前初值，初始高电平本身不会触发采样。极长时钟周期用完整内部状态相等来跳过重复拍；拍号到达可精确表示的整数上限后结束并提示。测试覆盖周期 10,000 及接近该上限的情况。

## 6. 和方案不一致的地方，以及原因

C2 范围及验收数字与方案一致。步进底座增加了可选的暂停标记，用来区分振荡后允许单步与机器已经结束两种状态；现有模拟器沿用原有播放行为。

反馈网表的首次重复可能相隔很久。「到稳定」按实际状态查重，额外验证了周期 323 的双环；对接近 200 个门且具有极长非重复序列的电路，未测定浏览器的等待时间。
