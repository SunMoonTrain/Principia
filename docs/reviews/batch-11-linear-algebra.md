- **小问题 1：`complex-eigenvalues:65` 动画的说明和默认画面对不上**
  - 说明写「插值途中的矩阵不是旋转，图形会先缩小一些」。可滑块默认 $a=b=1$ 时，图形一路变大，不会先缩小。
  - 道理：目标矩阵是 $\begin{pmatrix}a&-b\\b&a\end{pmatrix}$ 时，途中的 $(1-s)I+sA$ 也是这个样子，对应复数 $1+s(\lambda-1)$，网格一直是正方形。图形大小是 $|1+s(\lambda-1)|$：默认时是 $\sqrt{1+s^2}$，从 $1$ 单调增到 $\sqrt2$；只有 $a<1$ 时才会先缩小。
  - 导出了 $a=b=1$ 和 $a=0$、$b=1.5$ 两组、进度 $0$、$0.25$、$0.5$、$0.75$、$1$ 的画面：前一组单位圆的像半径一路变大，后一组中途比原来的圆小，和上面的计算一致。
  - 附录里「旋转矩阵插值途中不是旋转，图形会先缩小」说的是纯旋转（$a=\cos\theta<1$），这里照搬过来不成立。
  - 建议改成：「插值途中的矩阵也是$\begin{pmatrix}\alpha&-\beta\\\beta&\alpha\end{pmatrix}$的样子，网格一直是正方形，只是转的角度和倍数不是均匀变的；$a<1$时图形中途会先缩小。比较开头和结尾就行。」
